# ZACUT 15: בדיקות ושינויים

## שינויים שבוצעו

- גודל הגופן במכונת האותיות זהה בשמות בני ארבע וחמש אותיות, ללא הקטנת שמות בני חמש אותיות.
- מכונת האותיות הקטנה במפתח האותיות שבמילון והקישורים המהירים לערכים שולבו בגרסה הרגילה.
- חותמת טיפוגרפית של שם הערך במהדורה, במילון ובתוצאות החיפוש.
- אנימציית התכנסות האותיות בהחלפת ערך במהדורה, תוך כיבוד העדפת נגישות לצמצום תנועה.
- הוסרו **כל** רכיבי חיפוש שמות דומים לפי כתיב: חישוב מרחק עריכה, רשימת שכנים, לחצני מעבר וה־CSS הייעודי. הוסר גם מתג הניסוי וכותרת EXPERIMENTAL.

## בדיקות

- קובצי `data/zacut-corpus.json` ו־`data/site-content.json` זהים ברמת SHA256 לגרסה 14, כולל 469 ערכים וכל היסטי התיוג.
- HTML עצמאי: עשרה מסלולי ניווט נבדקו ברוחבי מסך 1440, 980, 768, 390, 340; בנוסף עשרה מסלולים באנגלית. לא זוהו שגיאות JavaScript או גלישה אופקית של העמוד.
- בדיקה מפורשת של שמות בני ארבע וחמש אותיות ב־`ZacutSH-001` וב־`ZacutSH-017`: גודל הגופן המחושב היה זהה, 129.6px ברוחב 1440.
- נבדקו חתימת שם במהדורה, אנימציית מעבר בערך, מפתח האותיות במילון, החותמות ברשימות המילון ובחיפוש.
- ZIP נבדק (תקינות ארכיון ומבנה שורש). בוצעה בדיקת דפדפן חלופית למבנה תת־הנתיב `https://elijah-dhlab.github.io/zacut/` באמצעות טעינת דף עם base מתאים וניתוב HTTP מקומי של קובצי האתר: נטענו CSS, JS, שני קובצי JSON והלוגואים המקומיים; המילון והחיפוש תפקדו. **לא בוצעה פריסה אמיתית לחשבון GitHub**.

## תלויות שלא השתנו

- שלושה לוגואים מוסדיים (`mlu.png`, `bgu.png`, `dfg.png`) מוזכרים בנתיבים מקומיים בקובץ התוכן אך אינם כלולים בחבילה, כפי שהיה בגרסה 14. באתר קיימים קישורי תמונה חיצוניים כגיבוי ושם המוסד כחלופה. בזמן סימולציית HTTP התקבלו תגובות 404 לנתיבים המקומיים הללו בלבד; לא לקובצי ליבה.
- חלק מתצלומי החוקרים נטענים מכתובות חיצוניות ויכולים שלא להופיע אם האתר המארח חוסם הטמעה.
- `index.html` של חבילת GitHub דורש HTTP, בניגוד לקובץ התצוגה העצמאי.
